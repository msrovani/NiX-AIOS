# Scripts de arquivo (histórico remigração s5xx)

**Não usar em produção.** O build canónico da ISO é:

```bash
bash scripts/build-iso.sh
```

Estes ficheiros preservam ondas s510–s528, pack FAT (`pack-usb-logfat`), e helpers s520.  
Doutrina 0.5.x: persistência Linux-first (`/var/lib/nosd`); FAT só lab opt-in.
